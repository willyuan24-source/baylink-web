# Share-card fonts

`NotoSansSC-Regular.ttf` and `NotoSansSC-Bold.ttf` are fixed-weight (400/700) instances of the Noto Sans SC variable font distributed by Google Fonts, instantiated with FontTools. The SVG renderer needs static instances to select weights correctly. They are used only during the build and are not shipped to website visitors.

Source: https://github.com/google/fonts/blob/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf
