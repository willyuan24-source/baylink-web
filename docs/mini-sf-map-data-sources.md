# Mini SF geographic data and runtime contract

Prepared 2026-09-24 (Pacific time). The checked-in map is an offline snapshot; opening `/play` does not make requests to DataSF or another mapping provider.

## Published geography

| Layer | Source | Use and limitation |
| --- | --- | --- |
| Shoreline and islands | [DataSF SF Shoreline and Islands, txuc-3kzm](https://data.sf.gov/d/txuc-3kzm), [dataset description](https://data.sf.gov/d/rgcx-5tix) | Real mainland coastline and Alcatraz outline. Keeps the mainland and Alcatraz; other islands belong to a later expansion. This historical shoreline snapshot is not a navigation or tide chart. |
| Street centerlines and names | [SF Public Works / DataSF Streets – Active and Retired, 3psu-pn9h](https://data.sf.gov/d/3psu-pn9h) | Source data as of 2026-09-24. Active streets only, no retired/paper streets, freeway lanes or ramps. Same-name connected segments are joined, then simplified for rendering. Street names and street class come from the source; widths are art-directed. |
| Neighborhood areas | [DataSF Analysis Neighborhoods, j2bu-swwd](https://data.sf.gov/d/j2bu-swwd), [metadata](https://catalog.data.gov/dataset/analysis-neighborhoods) | Uses the 40 mainland analysis areas, including Golden Gate Park and Presidio. These are grouped census tracts for statistical reporting, **not legally defined neighborhood boundaries**. Boundaries are scenery and district organization, not address classification. |

All three DataSF datasets use the [Open Data Commons Public Domain Dedication and License 1.0](https://opendatacommons.org/licenses/pddl/1-0/). Keep this visible attribution in the map credits: **San Francisco Public Works / DataSF. Simplified for BAYLINK Mini SF.**

Geometry is simplified offline with Shapely. The client JSON is 654,291 bytes and contains 15,396 original street segments merged into 5,196 paths, 2,392 street names, 40 neighborhood areas, and two land outlines. Treasure Island and Yerba Buena streets are excluded by their source neighborhood as well as road layer, since some island streets carry ordinary `STREETS` or `PRIVATE` layer labels. This keeps streets off islands that are not rendered. There are residential roads throughout the city, including districts without attractions. No fabricated business name, address or cadastral parcel is included. Generic building lots generated by the renderer must be described as scenery, never as real property boundaries.

## Projection and scenery

All geometry and landmarks use the same local projection:

```text
x = (longitude + 122.45) * 880
z = (37.77 - latitude) * 1113
```

North is negative z and east is positive x. A world unit is approximately 100 metres. Coastlines, streets, landmark coordinates and neighborhood rings share this projection; the city is not a rearranged theme park.

`terrainHeight(x,z)` adds smooth, art-directed hills at Twin Peaks, Mount Sutro, Russian Hill, Nob Hill, Telegraph Hill, Pacific Heights, Presidio and Alcatraz. This function is **not surveyed elevation**. Building dimensions, road widths, colors and plant placements are also artistic. The scene is for exploration and local content discovery, not street-by-street travel directions.

JFK Drive's eastern promenade, private roads, pedestrian segments and paths remain visible, but have `driveable: false` in this game snapshot. This flag is a conservative game access rule, not a complete or current legal road-access database. Cable-car operation and real road traffic restrictions require separate route data and should not be inferred from the world street network.

## Landmark anchors

All 17 approved places retain stable IDs: `bridge`, `presidio`, `palace`, `lombard`, `pier`, `alcatraz`, `chinatown`, `ferry`, `park`, `cable-car`, `twin-peaks`, `union-square`, `castro`, `skystar`, `coit`, `painted-ladies`, `sutro`.

Coordinates follow the approved design map and existing place catalog, with individual official/tourism sources attached to each record. Seven existing places map to BAYLINK `plannerPlaceId` and guide slugs. New places link to their official or tourism page until a BAYLINK guide is authored; they must not silently save an unrelated existing place.

Alcatraz's world anchor and shoreline are the island. `SF_ALCATRAZ_DEPARTURE` is the separate Pier 33 boarding point, matching [NPS arrival guidance](https://www.nps.gov/alca/planyourvisit/directions.htm). Never substitute the existing planner's ferry boarding coordinates for the island's location. The [SkyStar operator](https://www.skystarwheel.com/) places the wheel at Fisherman's Wharf near Pier 41; it is not positioned in Golden Gate Park.

## Runtime API

Import from `src/features/little-bay/sf-world.ts`:

- `SF_ROADS`: stable source CNN ID, name, class, artistic width, `driveable`, projected path.
- `SF_CITY_RINGS` and `SF_LAND_AREAS`: mainland and Alcatraz exterior rings.
- `SF_NEIGHBORHOODS`: name and projected rings.
- `SF_LANDMARKS`: stable ID, translated title, model kind, coordinate, projected position, arrival radius, optional existing guide and planner ID, source URL.
- `SF_MAJOR_STREET_LABELS`: readable major street label anchors and road heading.
- `projectCoordinate`, `unprojectPosition`, `terrainHeight`, `pointInRing`, `isOnLand`, `pointAlongRoad`.
- `nearestRoad(x,z,driveableOnly=false)`: grid-indexed closest road with `point`, `distance`, `segmentIndex`, interpolation `t`, and `heading=atan2(dx,dz)`. Use `true` for car movement and recovery, so walking paths do not become driving lanes.

The closest-road search checks the distance to all unsearched grid cells before accepting a hit and has a full fallback for distant camera queries. Scene building placement can use its distance to leave roads clear. The helper is not a turn-by-turn route planner and does not enforce one-way streets.

## Rebuild and verification

Run `python scripts/prepare-mini-sf-map.py` with Shapely installed; `--refresh` refreshes all source downloads. Cached sources are under `output/mini-sf-design`, never bundled. The runtime only imports `sf-geography.json`; no Python dependency is added to the app.

`tests/sf-world.test.ts` checks coordinate orientation and round trips, 17 stable anchors, the seven real guide mappings, mainland/ocean/island separation, residential and named street coverage, JSON size, walking-only exclusions, road projection, indexed/global nearest-road agreement and smooth scenery hills.
