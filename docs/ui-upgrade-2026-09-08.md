# BAYLINK UI 升级 · 2026-09-08

## 设计与交互

- 品牌视觉：暖白底、森林绿、浅柠檬绿，保留 BAYLINK 与 BayBay 水獭形象。
- 首页：定制湾区微缩景观主视觉、五类生活入口、宽屏信息流与探索侧栏。
- 浏览：可记忆的图卡／列表视图、快速搜索（Ctrl/Cmd + K）、地区示意图筛选、可清除筛选与加载反馈。
- 帖子：重排图片、价格、有效性状态与发布者信息；桌面分栏详情，手机固定联系入口。
- 指南：杂志式索引、搜索与分类、阅读进度、章节目录、可勾选清单。清单为当前阅读会话状态。
- 账户与发布：统一登录、消息、个人空间、三步发布流程和 BayBay 助手样式。
- 导航：桌面侧栏、手机底栏；页面切换与返回位置保留，覆盖层保持来源页面。

地区图是筛选用示意图，不提供定位、距离计算或精确地图导航。网站内容、价格、日期、认证说明和交易提醒继续使用原有真实数据与规则。
