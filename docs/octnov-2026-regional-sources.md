- Every record has explicit `occurrenceDates`, including continuous programs. The package is bounded to November 30: Marin lights continue into January, but this package lists only its four November nights. A range does not create additional performance dates.
- No central registry, feed, generated catalog, public assets, build output, or release was changed by this research task. English translations cover all Han-containing presentation strings in this package. Parent integration and final checks remain separate.
- `cost: unknown` means the opened source did not explicitly establish admission pricing. An absent fee, a public library venue, donations, or a public street location is not treated as proof of free admission.
- URLs whose paths retain “november-2025” are used only where the **page body explicitly states 2026**. Old 2025 schedules are not rolled forward.
- Two exact-location photo keys can be reused. Eighteen records initially leave `imageKey` empty pending the parallel media review. A named Commons candidate is not a downloaded or registered asset; permissions and the exact depicted scene must be checked before import. Official photos are **not** assumed reusable merely because the organizer is public or nonprofit. The parallel media owner is preparing independent context aliases/approved assets for parent integration.
