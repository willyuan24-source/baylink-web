# San Francisco and East Bay additions — September 27, 2026

## Scope and method

New module: `src/data/late-september-sf-east.ts`.
English dictionary: `src/data/late-september-sf-east-en.json`.

All records have `verifiedAt: 2026-09-27`. The module adds four confirmed October events (two per region) and two operating September openings (one per region). Event occurrence dates are single confirmed days, not inferred recurring schedules.

Before selection, all existing event and opening data modules were searched and their exported San Francisco/East Bay names and IDs inspected. These six subjects are new. Existing records such as Fleet Week, Oaktoberfest, Litquake Out Loud, Berkeley Harvest Festival, OMCA events, Broken Dreams and CHICHA San Chen were not duplicated. No shared registry, i18n, UI or media files were edited.
