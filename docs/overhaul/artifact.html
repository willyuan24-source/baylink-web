变量填什么
ANTHROPIC_API_KEY新的生产 key（只在 Render 里填，不要贴进聊天）
ANTHROPIC_WORKSPACE_ID只有 key 是组织级、Console 说需要时才填
ANTHROPIC_USE_UNTIL额度到期前一天，例如 2027-04-19T00:00:00Z。只能写 YYYY-MM-DD 或带 Z / 时区的完整时间，不能有空格；写错格式 BayBay 会马上停
AI_SPEND_SOFT_DAILY_USD4
AI_SPEND_HARD_DAILY_USD7

AI_GUEST_BAYBAY_DAILY_LIMIT建议 15（R1 测试用，你定）

想收花费提醒邮件，要打开 NOTIFICATION_DELIVERY_ENABLED=true。它会同时打开所有外发邮件（会员通知、登录提醒等），需要先配好 Resend（RESEND_API_KEY、RESEND_FROM_EMAIL、验证过的域名），并按 API 仓库（baylink-api）的 docs/g5-production-checklist.md 走一遍。不打开也行：每周自己看一眼 Console。
出问题时马上停 AI（911 急症卡照常）：BAYBAY_PAUSED=true。

怎么接手

换一个 Claude 账号，还是这台电脑

  • git、GitHub 登录和本机笔记都跟着电脑走，照常能用。Claude in Chrome 可能要重新配对。
  • 在一个中性文件夹开新会话（例如 C:/Users/willy/opus-qa），不要选 3D 世界那个文件夹。
  • 新账号有自己的周额度：告诉它这个账号的上限。

换到新 Mac

  • 不用把整台电脑的文件拷过去。代码都在 GitHub；交接文件在网站仓库（baylink-web）的 docs/overhaul/。
  • 装：Git、GitHub CLI（然后 gh auth login）、Node.js 24、Google Chrome、Claude 桌面版。
  • 建 ~/baylink，clone baylink-web 和 baylink-api。
  • 密钥不走 git：Render、Vercel 的设置留在后台不用动；评测 key 文件你在新电脑上重新建，放在仓库之外。
  • 想留历史：把旧电脑的 opus-qa/overhaul 和 opus-qa/audit-1013 打包私下拷走，不要放进公开仓库。
  • 换电脑前，请 Claude 把唯一没推上去的分支（Thrill-O-Ween 标"已取消"）推到 GitHub。
