# BAYLINK 阅读与发现升级

本轮围绕“先值得看，再愿意回来，最后自然参与”调整阅读路径。没有使用虚构的阅读量、热度、用户数或活动库存。

## 已实现的产品变化

- 首页将真实图文攻略放在首屏。周末出门、日常少麻烦、新来先安顿三种选择会切换主图、文章和相关入口；月刊及福利卡按湾区日期区分当期与往期。原分类、地区筛选和社区信息流保留。
- 文章增加收藏、分享和带当前文章的 BayBay 提问；指南页顶部可直接搜索。收藏可从 `/guides?view=saved` 找回，最近阅读与收藏可分开查看。收藏仅保存在当前浏览器，没有声称账户同步。
- 阅读架最多保存 80 个收藏和 12 条近期阅读；允许清空历史而保留收藏。存储不可用时保留本次会话并提示限制。服务端预渲染不包含任何本地阅读记录。
- 文末推荐保留编辑专题的优先顺序，并补足跨分类的后续阅读；过期月刊不会自动推荐为当期内容。
- 快捷搜索可直接搜索指南正文、切换结果并用键盘打开，也可将关键词传给 BayBay。中文输入法确认不会误提交。
- BayBay 支持当前标签页内连续追问，最多四轮完整问答作为请求上下文；当前文章优先作为参考。停止、关闭、超时和重试分别处理，旧请求不会覆盖新回答。服务端校验历史格式，并使用站内已发表内容和湾区日期回答，没有实时联网承诺。
- 增加金门公园免门票半日路线、Palo Alto Baylands 亲子观鸟路线，指南总数达到 39。两篇包含官方来源、不同实景照片、可切换分站路线、行动清单和交通/施工说明。资料详见 `reading-routes-sources-2026-09.md`。
- 首页搜索摘要及公开预渲染同步更新；新文章拥有独立 HTML、社交预览图、站点地图记录和明确路由。

## 验证方式

本轮覆盖阅读收藏持久化、跨标签页更新、坏存储与不可写存储、分享链接、搜索回退、过期推荐过滤、多轮对话、请求取消与超时、参考白名单及后端历史校验。发布前执行前端完整检查、后端测试，并用浏览器验收桌面和 390px 手机页面。发布后核对生产 HTML、静态图片、指南目录及实际 AI 请求。

前端完整检查：201 项测试通过，lint 无错误（44 项原有警告），成功构建 58 个公开 HTML 页面。离线发布预检确认两篇新文章、39 篇知识目录、8 张新图片和 sitemap 均一致。

## 效果判断

这些变化增加了入口可见性、内容密度和阅读后的下一步，但不等同于已经验证流量或发帖量增长。后续应观察首页到文章的点击、下一篇阅读、收藏使用以及阅读后开始发布的比例，再决定新增哪类内容。当前实现不为这些指标伪造数据，也没有增加外部追踪服务。
