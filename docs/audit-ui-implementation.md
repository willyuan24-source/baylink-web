# 2026-10-06 OPUS 审计：界面实施与复核记录

本次将 `REPORT.md` 中的建议作为待验证意见，按实际代码、内容与使用路径决定实施范围。这里记录最终界面行为；构建、整站测试和正式上线验收由发布记录汇总，本文不把中途测试或截图当作上线证明。

## 保留数据与需要后续验证的建议

- 所有原有指南收藏、活动想去、我的这周收藏、访客计划与账号计划的数据结构和存储仍保留。本次没有批量迁移或删除历史收藏；将来合并收藏入口需先设计兼容迁移、冲突处理与回退，再验证真实账号数据。
- 保留 3D 独立入口、现有游戏功能和旧实现回退材料。回退窗口最早到 2026-10-16；不能仅凭审计评分或未测量的「5%」假设提前删除旧代码。
- 字号与点击区域改善集中在信息阅读、主要导航及主要动作。本次不宣称所有遗留控件都已达到同一尺寸，也不把项目采用的 44px 目标等同于 WCAG AA 的所有条款。
- 首页意图选择是浏览器内偏好，不代表已验证的人群模型。最终要以匿名漏斗、真实访谈和持续使用观察检验；没有制造人气、收藏或参与计数。
- 邮件周报没有默认订阅既有用户。邮箱验证、主动订阅、退订、发送队列及运营计划需完成后再启用。

## 本轮子任务验证

完成的轻量组合：免费优惠图卡、指南媒体注册表、真实 WebP 尺寸与 480 响应资源、封面字节独立性、首页、图片标识、SEO、阅读字号与导航共 31 条，30 条通过。唯一失败是新增租客指南的宽泛安全推荐被带入兼职栏目；内容负责人已将推荐限定为租房/室友，完整指南链接断言已通过，SEO 原始质量要求保留。

另外独立完成：日期提醒下载 1/1、月刊官方海报的完整布局/来源标签 1/1。中文与英文公共服务示意图已目视检查，文字没有截断。

在整站测试期间发现 Node/JSDOM 资源竞争；已停止本子任务所有 Node 验证进程，由主发布流程串行进行最终测试。月刊全目录与活动详情新增契约未在本子任务中完成最终全量运行，必须以主流程的最终绿灯为准。活动详情测试仍覆盖全部已发布记录；Event 新断言核对真实日期、地址、无虚构票价及面包屑，优惠和新店保留 Article 约束。

正式发布前后还必须检查手机 390px、桌面、三种语言路径、Aa 字号、搜索/零结果、规划空状态/已有状态、活动已过期状态、助手卡片跳转，以及实际发布版本号。仅代码修改或构建成功不能代替这一验收。
