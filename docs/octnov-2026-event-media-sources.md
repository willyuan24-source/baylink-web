# October–November 2026 event photographs

Reviewed 2026-10-07. This package supplies 29 event image mappings (15 SF/East Bay and 14 Peninsula/South/North Bay), using 10 aliases of existing venue photographs and 13 new venue photographs. A fourteenth new photograph covers the Sonoma Plaza guide. It changes no event dates or verification dates.

All source photographs and reused assets were visually inspected. Captions explicitly separate the capture date from the 2026 event, identify the park/campus boundary, and avoid treating context photographs as a meeting-point map, event photograph, access guarantee, current program, or wildlife guarantee. No AI images were created or used. Only proportional resizing and WebP encoding were performed. No scene or color edits.

## Integration

- Merge `octnov-2026-event-media.json` into `GUIDE_IMAGES` before aliases.
- Apply `OCTNOV_EVENT_PHOTO_ALIASES` after their existing source keys are registered.
- Merge `OCTNOV_EVENT_CONTEXT_PHOTOS` into the exact event-ID allowlist.
- Apply `OCTNOV_EVENT_MEDIA_UPDATES` after both new event packages and any older image updates.
- Merge `octnov-2026-event-media-en.json` into the English dictionary. Simplified Chinese is authored here; Traditional Chinese uses the existing OpenCC locale conversion. All new visible alt, caption and credit text has an English entry.
- Map guide `sonoma-autumn-art-plaza-2026` to `octnov-sonoma-plaza-context`; this is the actual plaza, not a museum interior.
