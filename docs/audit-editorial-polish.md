# Editorial refinement — 2026-10-07

The previous audit pass improved task order and reading controls, but made the home page and guide index visually repetitive. This pass restores a warm white and forest-green palette, a restrained accent, real editorial photography, guide thumbnails and clearer heading rhythm. Image provenance stays visible; expandable credits retain author and license links. Event dates and titles precede their pictures. Posters and full-frame images remain uncropped.

The same pass closes concrete review gaps: AI activity and outing styles use the reading scale; offer and opening actions precede the long body; offer brands move out of the H1; Traditional Chinese post display has an original-text toggle; contact quota errors have three-language explanations. Mobile navigation keeps its accessible “Ask BayBay” name while the visible label is the shorter “BayBay”. The standard 72px navigation fits the tested 320px English/125% case without shrinking text.

Home image metadata is still generated into the small home catalog. Compact guide thumbnails advertise their actual 70/82/94px sizes. No new image service or dependency is required. A limited style guard checks the six reviewed scopes for reading tokens, palette references, focus styles and minimum explicit touch targets; it does not claim to audit all legacy CSS or the 3D canvas.

Engineering and content details are in [audit-editorial-engineering.md](audit-editorial-engineering.md). Site and 3D tests run in separate CI jobs, with the complete discovered test inventory and the existing required `check` aggregate. Hosting still verifies lint, dependencies, all generation, types, build, prerender, QR cards, calendars and release budgets. No test lane is skipped by file paths.

Local checks during development confirmed AI fact text at 17.5px, body at 20px, source text at 16.25px, 48px actions and a green keyboard outline in Traditional Chinese at 125%. A first full build passed the unchanged 220KiB home / 360KiB English-home budgets at 211.9/352.0KiB gzip. These are development observations, not a production release receipt. The final exact-commit CI, deployed versions and public UI evidence are recorded separately under the original OPUS audit's `implementation` folder.

Remaining boundaries are explicit: the new backend runtime aggregation does not itself produce a statistically meaningful production latency distribution; validated answer chunks are not provider token streaming. Shared-phone contact quotas do not prove unique personal identity. Future content gaps require real editorial supply, and refreshed review dates require actual source reads. Administrator MFA activation, hosting console controls, transaction delivery and the user's API budget remain account/operator work. A scheduled email newsletter and fully unified AI orchestration across plans, posts and outings are not represented as completed by this release.
