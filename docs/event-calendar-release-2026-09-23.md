# 活动日历与当天地图

入口 `/calendar`，首页、月刊、主导航、快捷搜索、智能计划及“我的这周”均可进入。月历 / 周历按湾区当地日期工作，默认今天；支持前后翻页、回到今天、跳转日期和地区筛选。日期按钮显示活动数量和类型圆点，选定日期同步城市筛选、地图标记、活动列表与加入计划链接。查询参数 `date`、`view`、`region` 可分享，并支持浏览器前进后退。

月历包含完整的周一至周日网格；邻月日期可点击。周历跨月和跨年保持七天。日期运算使用 UTC 中午，避免夏令时使日期跳跃。历史日期显示活动记录，不能从旧日期的卡片直接生成新计划；无活动或未收录日期不生成假活动。

地图只展示选定日期的活动，不混入常设景点。已有已核验的场馆坐标优先使用；其他活动按已核实的城市/区域参考点聚合。同一点显示场次数量，点击标记筛选列表，点击列表定位按钮选中对应点。城市/区域以虚线标记并明确声明不是入口。73 场目录活动覆盖 33 个城市或区域标签，其中 31 个城市、Sonoma County 及跨三市电影节两个区域标签；未将三市聚合中心当作影院。坐标来源见 `calendar-city-location-sources-2026-09-23.md`。

日期资料逐项审阅：50 单日、23 多日。Fleet Week 只标当前公布的 10/6–12；SVAFF 只标目前可确认公开放映的 10/10–11。其他项目使用已公布的连续日期；24 条说明保留各日时段、不同会场或门票边界。这里未重写原月刊总节期或修改旧 `verifiedAt`，无具体日期的项目不能由模型补写。来源及维护规则见 `event-calendar-schedule-sources-2026-09-23.md`。

沿用 MapLibre GL JS 6.11.1 和 OpenFreeMap，无新增依赖、付费 API、定位权限或后台服务。地图独立懒加载并保留署名，底图异常提供重试，列表仍可使用。页面有简体、繁体和英文；87 条新英文翻译包含日历、地图和所有日程说明。

验证包括日期边界与真实目录的 13 项单元测试、4 项页面交互测试，以及桌面 / 390px 手机浏览器检查。浏览器实际验证了选日期更换地图城市、Fremont 标记筛选当天电影、英文跨月周历、空日期移除旧点及无横向溢出。页面按现有方式静态预渲染并加入 sitemap 与 Vercel 路由。

全站 447 项测试通过；TypeScript、ESLint 无错误，生产构建输出 231 个 HTML 页面和 230 个 sitemap 项。
