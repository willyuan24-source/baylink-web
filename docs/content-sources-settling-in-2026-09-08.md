| [PG&E Start / Stop / Transfer](https://www.pge.com/en/account/service-requests/start-stop-transfer-service.html) | 新客户与现有客户的不同入口；服务地址、表具安全访问、起止日期；新建住宅及部分太阳能账户需要人工处理。正文不固化价格或承诺即日开通。 |
| [EBMUD Start or Stop Service](https://www.ebmud.com/customers/start-or-stop-service) | 开始、停止与范围内搬家转移供水；开户收费及方式可能不同。仅作为该供水区域的办理入口，不代表整个东湾或湾区。 |

| [USPS Forward Mail](https://www.usps.com/manage/forward.htm) | 临时／永久转寄、个人／同姓家庭、线上核验与现场补办；转寄不会更新银行、政府等记录，也不覆盖全部邮件。正文不固定认证费、转寄周期或投递耗时。 |
| [DMV 更新信息](https://www.dmv.ca.gov/portal/driver-licenses-identification-cards/updating-information-on-your-driver-license-or-identification-dl-id-card/) | 页面明确地址变更后十日内通知 DMV；有线上、邮寄、现场路径。正文限定已有 DMV 记录，不将其推导为移民、税务或其他机构的期限。 |

## 加州驾照及 ID 办理准备

| 官方来源 | 核验结果及正文用途 |
| --- | --- |
| [DMV Driver’s Licenses](https://www.dmv.ca.gov/portal/driver-licenses-identification-cards/driver-licenses-dl/) | 从未持照、有效外州驾照和外国驾照分列；外国驾照申请需要路考，页面另有路考往返陪同提醒。未成年人另有训练规则。正文不承诺免考、身份有效期或申请通过。 |
| [DMV ID Cards](https://www.dmv.ca.gov/portal/driver-licenses-identification-cards/identification-id-cards/) | ID 可证明身份／年龄但不授予驾驶权；普通 ID 与 REAL ID 选择、到场核验拍照等步骤。未固定费用、邮寄日期或个人资格。 |
| [REAL ID Checklist](https://www.dmv.ca.gov/portal/driver-licenses-identification-cards/real-id/real-id-checklist/) | 身份文件、姓名变更、两份不同打印住址文件；两份住址资料须符合姓名／邮寄地址要求；借用亲属住址证明需符合关系衔接规则，不能推广为任意室友账单。 |
| [What Is REAL ID](https://www.dmv.ca.gov/portal/driver-licenses-identification-cards/real-id/what-is-real-id/) | SSN 填报注明可能存在例外。正文要求按具体情况确认，没有把暂未收到 SSN 与符合例外等同。 |
| [AB 60 Driver’s Licenses](https://www.dmv.ca.gov/portal/driver-licenses-identification-cards/assembly-bill-ab-60-driver-licenses/) | 无法提供合法居留证明但满足身份、加州居住及其他要求的单独路径。核验了正确 `assembly-bill-ab-60-driver-licenses` 路径；旧 `ab-60-driver-licenses` 地址未能稳定读取，未使用。 |

不确定项：未审核个人移民状态、材料可接受性、SSN 例外、预约名额、办理中驾车许可或具体语言协助。文章明确由 DMV 按申请类型与材料确认；模板只整理询问，不收集证件号、不作为申请表。没有把普通 ID、REAL ID、驾照或 AB 60 混为一项业务。
