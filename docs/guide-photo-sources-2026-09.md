# BAYLINK 独立主题照片来源记录

核验日期：2026-09-08（America/Los_Angeles）。本批 14 张真实照片用于替换指南中重复的通用插画。逐张查看实际图像，并根据 Commons imageinfo 的 extmetadata 核对拍摄年份、作者、许可和来源。图片没有 AI 修改，也未替换照片内的地点或人物。

完整本地源文件 / Commons 官方缩略图保存在 `output/guide-distinct-originals/`，页面版本保存在 `public/guides/distinct/`，公开配图元数据位于 `src/data/guide-photo-assets.json`。除部分原图可直接获取外，其他文件采用 Commons 提供的 1280px 官方缩略图；全部保留宽高比，转为 WebP，并生成 480px 小图。卡片可以通过 CSS 裁切显示；未修改场景、人物或色彩。CC BY-SA 照片及这些缩放版本沿用原许可。

资料照片在可见图片说明里标明年份；春季 Filoli 照片不代表九月花况。柴犬和工具照片仅作主题示意，没有把它们标成湾区实拍或网站推荐的商家服务。
