# BAYLINK 图片覆盖与景点实拍展示

## 范围与结果

- 静态编辑内容共 241 个入口：76 篇攻略和编辑文章、93 个活动、55 条优惠、14 条新店资讯、3 个推荐地点。原来缺图的 30 个活动已逐条补图，当前图片解析缺失数为 0。详细来源与分类见 [图片覆盖审计](media-coverage-2026-09-24.md)。
- 76 篇攻略仍使用互不相同的封面源文件；其中 52 篇为照片，24 篇为明确标注的插图。活动的场地资料照或主题照片均说明用途，不代表当前活动现场。
- 匿名公开帖子接口分页核对完成：13 条帖子都有图片，29 个不同图片 URL 均返回 HTTP 200 和图片 MIME；没有修改用户发布的数据。检查时间为 2026-09-25 06:26 UTC（湾区 9 月 24 日）。
- 旧金山互动地图的 23 个景点分别绑定真实照片；新增 13 张授权照片及 480px 小图，其余沿用对应地点的现有素材。日本茶园、科学馆、de Young 和金门公园即使共享关联攻略，也各有独立照片。

## 用户界面

- 3D 景点入口显示“照片与攻略”或“景点照片”。地点名先于照片显示，关联攻略另列，避免把共用攻略标题误当成所选景点。
- 点击景点照片可查看大图、来源和许可；大图保留在游戏场景的对话框内，适用于场景全屏。Escape 先返回景点，再关闭详情；返回、失败重试后恢复键盘焦点，阅读时方向键不会穿透到场景移动。
- AI 活动卡片、日历当天活动、月刊 20 篇秋日攻略补上可见配图。行程地图展示当前选中的地点照片，保持列表紧凑，选择照片不会自动加入行程。
- 普通地点列表支持照片放大和失败重试。手机版详情由狭窄的侧栏图片改成横幅，月刊采用紧凑缩略图。
- 图片使用响应式 WebP 和按需加载，保留摄影作者、来源、许可及中英文说明。

- 图片审计：159 个注册媒体、319 个引用文件检查通过；317 个注册主图和小图完整解码通过。SF 地图独立检查 23 个实拍映射及其响应式文件。
- 浏览器：1365 × 900 桌面与 390 × 844 手机尺寸检查。覆盖 AI 活动、日历、月刊、行程地图、普通地点列表、SF 日本茶园及 SkyStar 照片。相关页面无横向溢出；图片加载、放大返回和英文说明正常。
- 场景扩大后的景点详情及大图检查通过；照片仍位于 `.sf-stage` 内。未声称完成实体手机硬件测试。
- `npm run check` 通过：611 项测试、0 失败；ESLint 0 错误、46 条警告；TypeScript 和生产构建通过，263 个公开 HTML 页面预渲染完成，238 张分享卡尺寸及直达链接二维码验证通过。Vite 仍提示部分既有大分块超过 500 kB。

## 维护

`scripts/audit-media-coverage.ts` 和回归测试会阻止空 imageKey、缺失文件、缺少来源说明以及未登记的活动照片复用。`event-image-usage.ts` 明确限制场地资料照和主题图的适用活动，原有活动现场图和海报仍不得任意跨活动借用。
