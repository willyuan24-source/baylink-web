# Bay Area attractions expansion — 2026-09-26

The attraction catalog grows from 18 to 28 places, with two new detailed guides in each of the five existing regions. All ten guides include official sources, suggested route order, three map links, arrival and return planning, family/mobility considerations, weather alternatives and a preparation checklist. Exact prices and operating hours are left to current official pages when not necessary to explain a decision.

| East Bay | USS Hornet / Alameda shoreline; Coyote Hills |
| Peninsula | Hiller Aviation Museum; Coyote Point / optional CuriOdyssey |

Each region filter now includes a short orientation and transport advice. Original city overview articles automatically link to the expanded catalog. This release excludes the separate Ferry Building attraction addition and all unfinished 3D-world changes.

## Planner coordinate evidence

The ten new places have individually checked coordinate evidence for planner integration; locations are areas, not surveyed entrances or guaranteed parking spaces. Hiller, Coyote Point, Computer History Museum, Rosicrucian and USS Hornet reuse previously checked coordinates. Additional evidence:

- Lands End Lookout: centroid of the [OSM visitor-center building](https://www.openstreetmap.org/way/250216260), checked via the OSM way API.
- Mission Dolores Park: [city facility page](https://sfrecpark.org/facilities/facility/details/missiondolorespark-188) embedded map coordinates.
- Coyote Hills: [official park page](https://www.ebparks.org/parks/coyote-hills) main entrance map link; this pin is east of the visitor center. Guide map links explicitly name the visitor center.
- Bear Valley: [NPS archived event location](https://www.nps.gov/planyourvisit/event-details.htm?id=6D8EBBB0-C198-DF22-5334984EC50153E5). The archive supports the location only, not a current event or schedule.
- Angel Island: [State Parks](https://www.parks.ca.gov/?page_id=468) directions coordinates by the arrival area. This is on the island, not a mainland ferry terminal.

English dictionaries, BayBay guide exports, planner coordinates/export, explicit hosting routes and share-card generation are integrated by the release coordinator. The release catalog contains 28 attractions and does not include the separate Ferry Building entry.
